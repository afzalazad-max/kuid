# KREATE UR ID

### Branding • Creative Design • Digital Marketing • Consultancy Services • Multimedia

KREATE UR ID is an independent branding, creative design, digital marketing, consultancy services, and multimedia studio based in Kochi, Kerala, India.

Founded by **Afzal Azad**, the studio partners with businesses, startups, entrepreneurs, artists, filmmakers, hospitality brands, and organizations to build memorable brands, create engaging digital experiences, and deliver strategic consultancy that drives sustainable growth.
